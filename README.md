# Pokesale

Klikbar frontend-prototype til en dansk Pokémon-PokeSalesplads.

## Start
Åbn `index.html` i en browser.

## Indeholder
- Forside og hero
- Søgning
- Kategorier
- Pris/set-filtre
- Sortering
- Favoritter
- Sælg-et-kort modal
- Oprettelse af nye demo-annoncer
- Responsive mobil-layout

Dette er frontend-only. Login, database, betaling, chat og rigtig billed-upload kræver en backend.
